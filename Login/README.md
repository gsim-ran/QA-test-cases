# Login Module Test Cases

## Overview

This folder contains manual test cases for the **Login** functionality of a web application. The test cases are designed to verify that users can securely authenticate and access the application using valid credentials while preventing unauthorized access.

## Objectives

- Verify successful login with valid credentials.
- Validate error messages for invalid login attempts.
- Ensure required field validations work correctly.
- Verify password masking and visibility functionality.
- Test account lockout and session management (if applicable).

## Test Coverage

The test cases cover the following scenarios:

- Valid Login
- Invalid Username
- Invalid Password
- Invalid Username & Password
- Empty Username
- Empty Password
- Empty Username & Password
- Password Visibility Toggle
- Remember Me Functionality
- Logout
- Session Timeout

## Testing Types

- Functional Testing
- Smoke Testing
- Regression Testing
- Exploratory Testing
