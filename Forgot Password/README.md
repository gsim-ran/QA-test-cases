# Forgot Password Test Cases

## Overview

This folder contains manual test cases for the Forgot Password functionality, ensuring users can securely reset their passwords.

## Objectives

- Verify password reset using a registered email.
- Validate email field.
- Verify reset link functionality.
- Validate password reset process.

## Test Coverage

- Registered Email
- Unregistered Email
- Invalid Email
- Empty Email
- Expired Reset Link
- Successful Password Reset

## Testing Types

- Functional Testing
- Regression Testing
