# Test Scenarios

## Overview

This folder contains high-level test scenarios for different modules of a web application. These scenarios serve as the basis for creating detailed test cases.

## Modules Covered

- Login
- Registration
- Forgot Password
- Shopping Cart
- Checkout

## Purpose

- Identify key functionalities for testing.
- Ensure complete feature coverage.
- Support effective test case design.

## Testing Types

- Functional Testing
- Smoke Testing
- Regression Testing
- Exploratory Testing
