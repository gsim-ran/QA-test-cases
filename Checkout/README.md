# Checkout Test Cases

## Overview

This folder contains manual test cases for the Checkout functionality of an e-commerce application.

## Objectives

- Verify successful checkout.
- Validate shipping information.
- Verify payment process.
- Confirm order placement.

## Test Coverage

- Shipping Address
- Payment Method
- Order Summary
- Place Order
- Payment Failure
- Order Confirmation

## Testing Types

- Functional Testing
- Regression Testing
