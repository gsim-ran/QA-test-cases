# Shopping Cart Test Cases

## Overview

This folder contains manual test cases for the Shopping Cart module of an e-commerce application.

## Objectives

- Verify product addition to cart.
- Verify product removal.
- Validate quantity updates.
- Verify cart total calculation.

## Test Coverage

- Add Product
- Remove Product
- Update Quantity
- Empty Cart
- Cart Total
- Continue Shopping

## Testing Types

- Functional Testing
- Regression Testing
- Exploratory Testing
